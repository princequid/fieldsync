# FieldSync Backend Documentation

## Project Overview

### Project Name
FieldSync

### Project Type
Field Operations Management Platform

### Backend Stack
- Node.js
- Express.js
- Apollo GraphQL
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs

## Purpose of Backend

The backend handles:
- User authentication
- Role-based authorization
- Job management
- Workflow management
- Notifications
- Dashboard statistics
- Data persistence
